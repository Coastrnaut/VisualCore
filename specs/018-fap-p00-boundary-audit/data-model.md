# Data model: A02-P00

Uses the shared app-contract schema 1 defined in
[`specs/011-gas-p00-boundary-audit/data-model.md`](../011-gas-p00-boundary-audit/data-model.md) and checked by
`scripts/check_app_contract.py`: `inventory[]`, `matrix[]` (id M01–M10, capability, source, status, evidence[],
example, notes), `gaps[]` (id, matrix, kind, owner, phase, test), `traceability[]`, `negative[]` and `decision`. The
app slug is `fluid-art-playground`. No app documents exist in this phase.
