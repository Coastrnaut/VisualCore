
**App-owned sources** come later, in `Packages/ExperiencesCreative/DigitalZenGarden/{Core,CoreTests,Experience,
ExperienceTests}` (A20-P01). Their dependency direction will be experience → VisualCore products
(`VisualCoreRendering`, `VisualCoreScenes`, `VisualCoreMath`, `VisualCoreSimulation`, `VisualCorePersistence`,
`VisualCoreExperience`, `VisualCoreExperienceHost`, `VisualCoreUI`, `VisualCoreAudio`, `VisualCoreAudioDSP`), never the reverse. There is no Swift, project or
package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread and delivers touches through `pointerHandler`; the presenter turns them
  into actions and never changes the state itself.
- The experience host owns open, suspend, resume and close, preparation with cancellation, pointer cancellation on
  suspend, and memory warnings.
- Scenes create GPU objects in setup and release them in teardown; `PingPongTarget` is invalidated on context loss and
  rebuilt from CPU state.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
