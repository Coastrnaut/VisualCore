
**App-owned sources** come later, in `Packages/ExperiencesCreative/LivingWallpapers/{Core,CoreTests,Experience,
ExperienceTests}` (A19-P01). Their dependency direction will be experience → VisualCore products
(`VisualCoreRendering`, `VisualCoreScenes`, `VisualCorePersistence`, `VisualCoreExperience`,
`VisualCoreExperienceHost`, `VisualCoreDiagnostics`, `VisualCoreUI`), never the reverse. There is no Swift, project or
package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread; `renderOffscreen` runs there, validates the size before GPU work, and on
  every path releases its target and restores the live scene.
- The experience host owns open, suspend, resume and close, preparation with cancellation, and memory warnings.
- Scenes create GPU objects in setup and release them in teardown.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
