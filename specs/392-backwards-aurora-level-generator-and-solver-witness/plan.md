# Implementation Plan: R02-G10-02 — Backwards Aurora: level generator and solver witness

**Branch**: `392-backwards-aurora-level-generator-and-solver-witness` (spec directory only; work on `main`) | **Date**:
2026-11-22 | **Spec**: [spec.md](spec.md)

## Summary

Extend `BackwardsAuroraCore` with the content pipeline on the pattern of Nocturne Garden's (feature 382): the 100-entry
manifest with provenance, band profiles (wave length, reversal range, section lengths, checkpoints, breaking margin), a
seeded candidate generator that builds the opening from a gently curving target by reversing k separated sections whose
seams all break the bend limit, the seam-count lower bound ⌈β / 4⌉ of clarification Q2 (β the bad bends), an
iterative-deepening solver over reversible sections that finds a winning sequence at that bound with counted work,
difficulty metrics, witness files with per-reversal sample digests and the near miss, the catalog digest and the
progression check. Research: [research.md](research.md). Data: [data-model.md](data-model.md). API:
[contracts/api.md](contracts/api.md). Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6. **Primary dependencies**: VisualCoreSimulation (`SeededRandom`, `SeedDerivation`,
`PuzzleCatalog.digest(id:identities:)`, `ProgressionRule`, `PuzzleDifficulty`) and VisualCoreMath (`StableHash`). No GPU
or UI code; no new target.
**Numbers**: waves of 14 … 32 samples; at most 32 · 31 / 2 = 496 sections per node; a solution of k ≤ 7 reversals; work
counted in reversals evaluated (bound 20,000 per level). Because the bound is tight (every move on a solution at the
bound must remove 4 bad bends), the search at the starting bound examines few nodes.
**Seeds**: candidate c of entry n uses `SeedDerivation.derive(plannedSeed, index: c)`; fixtures seed 2_392.
**Testing**: `swift test --package-path Packages/ExperiencesRound02 --filter BackwardsAurora`; catalog tests in groups
of 5.
**Performance**: measured per group locally (under 10 s on a debug host build); not asserted on CI.
**Constraints**: additive; R02-G10-01's types unchanged except two new error cases; witness files written only with
`BACKWARDS_AURORA_WRITE_WITNESSES=1`.

## Parallel work

The lead writes the error cases, the manifest, the solver, the difficulty and the generator; agents A (solver tests
with an independent check), B (witness and its tests) and C (generator tests) then work in parallel against the
contract; the lead writes the catalog tests and the witness files, retests every agent result and records checks only
after every agent has reported.
