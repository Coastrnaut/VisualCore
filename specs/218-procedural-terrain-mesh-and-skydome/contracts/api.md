# Contract: public API (R02-F18)

VisualCoreScenes (pure). Throwing members use typed throws.
- `public enum TerrainError: Error, Equatable, Sendable { case terrainSize(Int), pieceSize(Int), levelCount(Int), levelDistance, budget(Int), viewpoint, newerSchema(Int), malformed(String); public var reasonCode: String }`
- `public struct TerrainSettings: Sendable, Equatable, Codable { public static let schema = 1; public let pieces, pieceCells, levels, vertexBudget: Int; public let cellSize, levelDistance: Double; public init(pieces: Int, pieceCells: Int, cellSize: Double, levels: Int, levelDistance: Double, vertexBudget: Int = 262_144) throws(TerrainError); public var size: Double /* pieces · pieceCells · cellSize */; public func encoded() -> Data; public static func decode(_ data: Data) throws(TerrainError) -> TerrainSettings }`
- `public struct TerrainPiece: Sendable, Equatable { public let column, row, level: Int; public let coarserNeighbours: [Bool] /* −z, +x, +z, −x */; public let originX, originZ, cellSize: Double; public let cells: Int; public var vertexCount: Int }`
- `public enum TerrainLOD { public static func select(_ settings: TerrainSettings, viewpoint: Vec3) throws(TerrainError) -> [TerrainPiece] /* row-major, row = z index */; public static func mesh(for piece: TerrainPiece, height: (Double, Double) -> Double) throws(MeshError) -> Mesh }` — a viewpoint that is not finite → `viewpoint`; budget the coarsest tiling exceeds → `budget(needed)`. The mesh has (cells + 1)² vertices in row-major order, y up, counter-clockwise from +y, normals from `HeightField`, and its odd points on coarser-facing edges at the mean of their even neighbours.
- `public enum ErosionMask { public static func masks(of field: HeightField) -> FieldGrid /* (columns + 1) × (rows + 1), 3 channels */ }`
- `public enum SkyError: Error, Equatable, Sendable { case skyParameter(String), direction, newerSchema(Int), malformed(String); public var reasonCode: String }`
- `public struct SkyParameters: Sendable, Equatable, Codable { public static let schema = 1; public var zenith, horizon, ground, dusk, night, sunColour: Vec3; public var sunRadius, glowStrength, glowExponent: Double; public init() /* defaults */; public func validated() throws(SkyError) -> SkyParameters; public func encoded() -> Data; public static func decode(_ data: Data) throws(SkyError) -> SkyParameters }`
- `public enum SkyModel { public static func colour(direction: Vec3, sun: Vec3, parameters: SkyParameters) throws(SkyError) -> Vec3 }` — zero or non-finite vectors → `direction`; both are normalised first.

VisualCoreRendering.
- `vc/sky.glsl`: `vec3 vc_sky(vec3 d, vec3 s, vec3 zenith, vec3 horizon, vec3 ground, vec3 dusk, vec3 night, vec3 sunColour, vec3 sunShape /* radius, glowStrength, glowExponent */)` — the clarification Q4 expression, d and s normalised inside.
- `public final class SkyRenderer { public init(registry: ResourceRegistry) throws; public func draw(inverseViewProjection: Mat4, sun: Vec3, parameters: SkyParameters) throws; public func release() }` — the `PlanarShadowRenderer` pattern (registry at init, `release()` frees the program); draws one far-plane triangle (depth LEQUAL, no depth write) into the bound framebuffer and viewport, restoring the program, depth and blend state it changes.
