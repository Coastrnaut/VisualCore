# Implementation Plan: R02-G04-02 — Hue Compass: level generator and solver witness

**Branch**: `332-hue-compass-level-generator-and-solver-witness` (spec directory only; work on `main`) | **Date**:
2026-11-21 | **Spec**: [spec.md](spec.md)

## Summary

Extend `HueCompassCore` (R02-G04-01, feature 331) with the content pipeline of Hue Compass: the 100-entry manifest
(`HueCompassManifest`), the deduction solver (`HueCompassSolver`: the smallest probe set, depth bound 2, after which every
target consistent with the clues is accepted by one selection), difficulty metrics (`HueCompassDifficulty`), the seeded
generator (`HueCompassGenerator`: offset, fog with the band's clear share, target, start, band tolerances; candidates
until one is proven within its band) and versioned witness files (`HueCompassWitness`, schema 1) under
`docs/games/hue-compass/levels/`. The catalog digest is R02-F24's `PuzzleCatalog<HueCompassRules>.digest(id:identities:)`,
pinned. Research: [research.md](research.md). Data: [data-model.md](data-model.md). API: [contracts/api.md](contracts/api.md).
Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6. **Primary dependencies**: HueCompassCore's own types (`HueCompassLevel`, `HueCompassWheel`,
`HueCompassPlay`, `HueCompassRules`); VisualCoreSimulation (`SeededRandom`, `SeedDerivation.derive(_:index:)`,
`PuzzleCatalog.digest(id:identities:)`, `ProgressionRule`); VisualCoreMath (`StableHash`). No GPU, GLSL or UIKit code; no
new package or target.
**Seeds**: level n uses its manifest seed; candidate k draws from `SeededRandom(seed: SeedDerivation.derive(seed, index:
k))`, k = 0 … 63. Brute-force cross-checks use seed 2_332.
**Testing**: `swift test --package-path Packages/ExperiencesRound02` (CI step exists); regression as for 331 (VisualCore
host tests, VisualCoreRendering on sim-27.2 and sim-26.5, ExperiencesCreative on sim-27.2, the reference regression in
two chunks, script tests alone).
**Performance**: the solver tries at most 4,657 probe sets per level, each classifying at most 96 candidates through a
precomputed 96 × 96 clue table; a class is checked by its circular bearing span (≤ 2 × bearing tolerance) and band span
(≤ 2 × band tolerance). Target: a level's generation well under 0.1 s on a debug host build on average; catalog tests split
by band (20 levels each) so each stays under 10 s; CI timings measured, never asserted.
**Constraints**: additive to R02-G04-01's public API; allowance = the manifest move budget (8 … 19); every value an exact
integer; no network, no art; witness files written only with `HUE_COMPASS_WRITE_WITNESSES=1`.

## Parallel work

Lead first adds the error cases, the manifest, the solution and difficulty contract (contracts/api.md) and the difficulty
type; agents A (solver and its tests) and B (witness and its tests) then work in parallel against the contract; the lead
writes the generator, the catalog tests and the witness files once A's solver is in, retests every agent result and
records checks only after every agent has reported.
