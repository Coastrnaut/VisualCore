**App-owned sources** come later, in `Packages/ExperiencesCreative/GraphicsBenchmarkLab/{Core,CoreTests,Experience,
ExperienceTests}` (A24-P01). Their dependency direction will be experience → VisualCore products, never the reverse:
- `VisualCoreDiagnostics`, `VisualCorePersistence`, `VisualCoreExperience`, `VisualCoreMath`, `VisualCoreSimulation`;
- `VisualCoreRendering`, `VisualCoreExperienceHost`, `VisualCoreUI`.

The core uses only the pure products. There is no Swift, project or package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread. Workload programs and textures are created only inside a scene's `setup`,
  `resize` or `render` with its context current.
- The experience host owns open, suspend, resume and close, preparation with cancellation, and memory warnings. A
  suspension or context loss during a run marks the run interrupted; resources are rebuilt from CPU state.
- Scenes create GPU objects in setup and release them in teardown.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
