# Research: A01-P00

- **R1 Contract format.** Decision: one JSON file per app (`docs/apps/<slug>/visualcore-contract.json`, schema 1),
  plus a Markdown view generated by the checker's `--render`. Rationale: data stays machine-checkable while the view
  stays readable, and the same tool serves all 25 apps. Alternatives: Markdown tables parsed by regex (fragile);
  YAML (needs a non-stdlib parser).
- **R2 Symbol verification.** Decision: a cited symbol must match a declaration regex in the cited file:
  `(class|struct|enum|protocol|actor|func|var|let|typealias|case|init)\s+<name>`. A `Type.member` citation checks
  both the type and the member. A public citation additionally needs `public` on the declaration line, which ensures
  evidence is real API, not internals. Alternatives: SourceKit indexing (heavy, slow); grepping the API baseline
  only (it misses the file binding).
- **R3 Capability rows.** The 6 brainstorm capabilities plus 4 version-0.1 needs: seeded reproducibility,
  versioned local documents, offscreen still export with color space, and pause/time scrub/reduced motion.
- **R4 Audit findings (read-only, verified against the API baseline `docs/api/visualcore-public-api.txt`).**

  | Capability | Status | Evidence | Gap, and the module that will own it |

  | Animation and time | requires adaptation | `Timeline`, `Tween`, `FixedStepClock`, `RenderHost.pause/resume` | A pausable, scrubbable, speed-scaled scene clock goes to VisualCoreSimulation (`SceneClock`). |
  | Render targets | available | `ResourceRegistry.makeRenderTarget`, `RenderTarget.readPixels`, `EffectScene` | — |

Reusable by apps 2, 3, 22 and 25. |
  | Touch and gestures | available | `PointerTracker`, `TapRecognizer`, `DragRecognizer`, `PinchRecognizer`, `RenderHost.pointerHandler` | — |
