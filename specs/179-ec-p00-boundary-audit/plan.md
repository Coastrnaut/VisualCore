**App-owned sources** come later, in `Packages/ExperiencesCreative/EffectsComposer/{Core,CoreTests,Experience,
ExperienceTests}` (A25-P01). Their dependency direction will be experience → VisualCore products, never the reverse:
- `VisualCoreParameters`, `VisualCorePersistence`, `VisualCoreExperience`, `VisualCoreShaderSource`,
  `VisualCoreScenes`, `VisualCoreDiagnostics`, `VisualCoreMath`;
- `VisualCoreRendering`, `VisualCoreExperienceHost`, `VisualCoreUI`.

The core uses only the pure products. There is no Swift, project or package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread. Pass programs and targets are created only inside a scene's `setup`,
  `resize` or `render` with its context current.
- The experience host owns open, suspend, resume and close, preparation with cancellation, and memory warnings. A
  context loss rebuilds targets and re-uploads the source from bytes kept on the CPU.
- Scenes create GPU objects in setup and release them in teardown.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
