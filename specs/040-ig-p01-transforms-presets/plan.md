**Dependency direction**: Experience → Core → VisualCore products; app → Experience product. **Lifecycle**: the host
owns the context; the presenter creates its renderers in `setup`, releases them in `teardown`, rebuilds after a
context recreation; the composition is rebuilt from core state on change (cached by the state's digest).
**Schema**: core snapshot = Codable core (preset, seed); `MigrationChain(currentVersion: 1)`. **Rollback**: revert the
commits; the registration leaves with them.

Agent C: Experience (adapter, manifest, presenter, controls, factory) + ExperienceTests. Lead: Package.swift,
registration, registry, project.yml, docs, baseline, every run and commit.
