# Implementation Plan: R02-G07-02 — Amethyst Escape: level generator and solver witness

**Branch**: `362-amethyst-escape-level-generator-and-solver-witness` (spec directory only; work on `main`) | **Date**:
2026-11-22 | **Spec**: [spec.md](spec.md)

## Summary

Extend `AmethystEscapeCore` with the content pipeline on the pattern of Chrono Constellator's (feature 352): the 100-entry
manifest with provenance, band profiles, a seeded candidate generator, a breadth-first solver over crystal states that
proves the smallest move count (clarification Q2), difficulty metrics, witness files with per-move digests and
counterexamples, the catalog digest and the progression check. Research: [research.md](research.md). Data:
[data-model.md](data-model.md). API: [contracts/api.md](contracts/api.md). Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6. **Primary dependencies**: VisualCoreSimulation (`SeededRandom`, `SeedDerivation`,
`PuzzleCatalog`, `ProgressionRule`, `PuzzleDifficulty`) and VisualCoreMath (`StableHash`). No GPU or UI code; no new target.
**Numbers**: a state packs the offsets and the pearl into one integer (at most 10^4 × 4 × 10 = 400,000 states for the
band-5 profile); the search uses arrays indexed by state, never hashing in the hot loop.
**Seeds**: candidate k of entry n uses `SeedDerivation.derive(plannedSeed, index: k)`; fixtures seed 2_362.
**Testing**: `swift test --package-path Packages/ExperiencesRound02 --filter AmethystEscape`; catalog tests one per band.
**Performance**: measured per band locally (a band's certification under 10 s on a debug host build); not asserted on CI.
**Constraints**: additive; R02-G07-01's types unchanged except two new error cases; witness files written only with
`AMETHYST_ESCAPE_WRITE_WITNESSES=1`.

## Parallel work

The lead writes the error cases, the manifest, the solver, the difficulty and the generator; agents A (solver tests with
an independent brute force), B (witness and its tests) and C (generator tests) then work in parallel against the
contract; the lead writes the catalog tests and the witness files, retests every agent result and records checks only
after every agent has reported.
