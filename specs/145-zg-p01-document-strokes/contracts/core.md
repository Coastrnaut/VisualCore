# Contract: Digital Zen Garden core (A20-P01)

- **Document:** encoding then decoding gives an equal document; one sample per refusal of data-model.md is refused
  with its code and leaves the open garden unchanged.
- **Resampling:** every neighbouring pair is at most 0.004 + 1e-9 apart; at most 512 points; clamped to the tray; a
  non-finite point refuses.
- **Rakes:** the two styles differ in tines, width and depth; a stamp changes only cells within its footprint.
- **History:** 50 or more commands undone and redone give an identical command list and a field within 1e-6 per cell;
  a new command clears redo; beyond 100 commands the oldest folds into the checkpoint and rebuilding from it equals
  rebuilding from the start within 1e-6; undo and redo with empty lists change nothing.
- **Purity:** no GL, UIKit, SwiftUI, network or clock in the core.
- **As built:** the builders, depth-ordered stones, the command refusal codes and the ridge count of data-model.md
  "As built" (HistoryTests, RakeTests).
