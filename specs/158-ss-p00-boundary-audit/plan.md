**App-owned sources** come later, in `Packages/ExperiencesCreative/ShaderStudio/{Core,CoreTests,Experience,
ExperienceTests}` (A22-P01). Their dependency direction will be experience → VisualCore products, never the reverse:
- `VisualCoreShaderSource`, `VisualCoreParameters`, `VisualCorePersistence`, `VisualCoreExperience`;
- `VisualCoreDiagnostics`, `VisualCoreRendering`, `VisualCoreExperienceHost`, `VisualCoreUI`.

The core uses only the pure products. There is no Swift, project or package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread. Programs are compiled only inside a scene's `setup`, `resize` or `render`
  with its context current, and a failed compile leaves any held program untouched.
- The experience host owns open, suspend, resume and close, preparation with cancellation, and memory warnings.
- Scenes create GPU objects in setup and release them in teardown. Programs and textures are rebuilt from the
  project's source after a context loss or resize.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
