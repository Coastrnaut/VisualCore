# Contract: public API (R02-F17)

VisualCoreSimulation (pure). Throwing members use `throws(HeightfieldError)`. Flux and neighbour order everywhere:
up (y − 1), right (x + 1), down (y + 1), left (x − 1).
- `public enum HeightfieldError: Error, Equatable, Sendable { case gridSize, cellRange(Int), amountLimit, invalidTime, invalidParameter(String), dyeChannel(Int), newerSchema(Int), malformed(String); public var reasonCode: String }`
- `public enum HeightfieldEdges: String, Sendable, Codable, CaseIterable { case walled, open }`
- `public struct HeightfieldParameters: Sendable, Equatable, Codable { public var gravity = 9.81, pipeArea = 1.0, damping = 0.995, maxSubstep = 1.0 / 120, maxSubsteps = 64, erosion = false, capacity = 0.05, dissolving = 0.3, depositing = 0.3; public init(); public func validated() throws -> HeightfieldParameters }` (ranges in data-model.md; `invalidParameter(<name>)`).
- `public struct HeightfieldLedger: Sendable, Equatable, Codable { public struct Account: Sendable, Equatable, Codable { public internal(set) var added: Int64; public internal(set) var removed: Int64; public internal(set) var drained: Int64; public var net: Int64 /* added − removed − drained */ }; public internal(set) var water: Account; public internal(set) var rock: Account /* terrain + sediment */; public internal(set) var dye: [Account] }`
- `public struct HeightfieldStepReport: Sendable, Equatable { public let substeps: Int; public let substepDuration: Double; public let droppedTime: Double; public let fluxClamped: Bool }`
- `public struct Heightfield: Sendable, Equatable { public static let quantaPerUnit: Int64 = 65_536; public static let maxAmount: Int64 = 1 << 40; public static let minSide = 4; public static let maxSide = 1_024; public static let maxCells = 262_144; public static let maxDyeChannels = 4; public static let maxFlux = 1_000_000.0; public let width, height, dyeChannels: Int; public let edges: HeightfieldEdges; public let parameters: HeightfieldParameters; public private(set) var ledger: HeightfieldLedger; public init(width: Int, height: Int, dyeChannels: Int = 0, edges: HeightfieldEdges = .walled, parameters: HeightfieldParameters = .init()) throws; public func cell(x: Int, y: Int) -> Int /* y·width + x */; public func terrain(at cell: Int) -> Int64; public func water(at cell: Int) -> Int64; public func sediment(at cell: Int) -> Int64; public func dye(_ channel: Int, at cell: Int) -> Int64; public func flux(at cell: Int) -> [Double] /* 4 values */; public mutating func add(terrain: Int64, at cell: Int) throws; public mutating func add(water: Int64, at cell: Int) throws; public mutating func add(dye: Int64, channel: Int, at cell: Int) throws; @discardableResult public mutating func remove(water: Int64, at cell: Int) throws -> Int64 /* removes min(asked, present) */; @discardableResult public mutating func remove(terrain: Int64, at cell: Int) throws -> Int64; @discardableResult public mutating func remove(dye: Int64, channel: Int, at cell: Int) throws -> Int64; /* sediment has no edit: it changes only by erosion and flow */ public var totalWater: Int64; public var totalRock: Int64 /* terrain + sediment */; public func totalDye(_ channel: Int) -> Int64; public var isBalanced: Bool /* every total equals its ledger net */; public func surface(at cell: Int) -> Double /* (terrain + water) in height units */; public mutating func step(by time: Double) throws -> HeightfieldStepReport; public func fieldGrid() -> FieldGrid /* 4 channels: terrain, water, sediment, total dye, in height units (FieldGrid holds at most 4) */; public func dyeField() -> FieldGrid? /* one channel per dye, nil without dye */; public func encoded() -> Data /* JSON, sorted keys */; public static func decode(_ data: Data) throws -> Heightfield }` and `Codable`.
- Limits: the 2⁴⁰ bound applies to every cell and to every quantity's grid total, so flow can never push a cell past it.
- Refusals: sides outside 4 … 1,024 or more than 262,144 cells → `gridSize`; dye channels outside 0 … 4 → `dyeChannel`; a cell outside the grid → `cellRange(cell)`; a channel outside 0 ..< dyeChannels → `dyeChannel(channel)`; a negative amount or a result above 2⁴⁰ → `amountLimit`; a time that is negative or not finite → `invalidTime`; parameters outside their ranges → `invalidParameter(name)`; schema above 1 → `newerSchema`; damaged JSON or arrays of the wrong size → `malformed`.
