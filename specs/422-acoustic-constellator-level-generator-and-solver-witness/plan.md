# Implementation Plan: R02-G13-02 — Acoustic Constellator: level generator and solver witness

**Branch**: `422-acoustic-constellator-level-generator-and-solver-witness` (spec directory only; work on `main`) |
**Date**: 2026-11-23 | **Spec**: [spec.md](spec.md)

## Summary

Extend `AcousticConstellatorCore` with the content pipeline, on the pattern of Harmonic Bridges's (feature 412): the
100-entry `AcousticConstellatorManifest` from the archived design; band profiles (star counts, missing symbol pairs,
windows); a constructive generator per manifest entry (a spanning-tree symbol plus a cycle from band 3, near-equal
rates, drawn starting phases, some symbol pairs fixed and the rest missing, the coupling, snap limit, hold and window,
derived limits and threshold); a solver that finds the minimal action set (the missing symbol pairs plus the fewest
helper links and phase nudges) by trying ever larger extra sets in a fixed order and running the kernel's listen on
each, counting work against a bound of 400,000 listens and storing the count of smaller sets tried as the minimality
proof; difficulty metrics; witness files with per-action state digests and the counterexample; the catalog digest and
the progression rule. Research: [research.md](research.md). Data: [data-model.md](data-model.md). API:
[contracts/api.md](contracts/api.md). Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6. **Primary dependencies**: VisualCoreSimulation (`SeededRandom`, `SeedDerivation`,
`PuzzleCatalog`, `ProgressionRule`, `PuzzleDifficulty`) and VisualCoreMath (`StableHash`), already linked by
`AcousticConstellatorCore`. **Numbers**: at most 8 stars, 28 pairs and 16 nudge options; listens bounded at 400,000 per
candidate (the prototype needed at most 6,657); plain `Int` arithmetic. **Seeds**: manifest seeds through
`SeedDerivation`; test fixtures seed 2_422. **Testing**: `swift test --package-path Packages/ExperiencesRound02 --filter
AcousticConstellator`; catalog certification in groups of 5 levels, each under 10 s on a debug host build (measured
locally, not asserted on CI); generated levels cached per process. **Constraints**: additive; reason codes
`r02-g13.*`; no clock in any rule.

## Parallel work

The lead writes the error cases, the manifest, the solver, the difficulty and the generator; agents A (solver tests
with an independent brute force), B (witness and its tests) and C (generator tests) then work in parallel against the
contract in isolated copies; the lead writes the catalog tests and the witness files, retests every agent result and
records checks only after every agent has reported.
