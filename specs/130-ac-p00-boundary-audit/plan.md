**App-owned sources** come later, in `Packages/ExperiencesCreative/AmbientClock/{Core,CoreTests,Experience,
ExperienceTests}` (A18-P01). Their dependency direction will be experience → VisualCore products
(`VisualCoreSimulation`, `VisualCoreParameters`, `VisualCoreRendering`, `VisualCorePersistence`,
`VisualCoreExperience`, `VisualCoreUI`), never the reverse. There is no Swift, project or package change now.

**Lifecycle contracts**, inventoried and not changed:
- `RenderHost` owns EGL on the main thread and paces frames to `maxFramesPerSecond`.
- The experience host owns open, suspend, resume and close; resume does not catch up on suspended time.
- Scenes create GPU objects in setup and release them in teardown.

**Data schemas:** the contract JSON only. **Migration and rollback:** documents only; revert the commits.
