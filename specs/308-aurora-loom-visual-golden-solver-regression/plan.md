# Implementation Plan: R02-G01-08 — Aurora Loom: visual golden and solver regression

**Branch**: `308-aurora-loom-visual-golden-solver-regression` (spec directory only; work on `main`) | **Date**:
2026-11-20 | **Spec**: [spec.md](spec.md)

## Summary

Add a regression net around Aurora Loom without changing its rules. In the host-tested `AuroraLoomCore`: a solver
regression over the 100 certified levels (witness replay, exact re-solve within 3,840 evaluations, twelve kinds of
alteration detected and named) and `AuroraLoomGolden`, which computes the code-only description of 16 golden frames
(5 levels × 3 tiers plus the hero frame) and its SHA-256 digests; descriptions and digests are pinned in
`golden-frames.json` (an equal digest passes, else positions within one 1/8-pixel quantum and equal colours) and
rewritten only with `AURORA_LOOM_WRITE_GOLDEN=1`. In the iOS experience tests: the 16 golden frames rendered and checked against their
descriptions, and 12 open-draw-warn-close memory cycles measured with `ProcessMemory.footprint()` while the ribbon scene
reports zero live GPU objects after each close and warning. A local script runs every part with one summary; CI gains a
named step for the host part. Research: [research.md](research.md). Data: [data-model.md](data-model.md). API:
[contracts/api.md](contracts/api.md). Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6; Python 3 for the local script. **Primary dependencies**: AuroraLoomCore (generator,
solver, witness, scene geometry, shaders' CPU references); VisualCoreMath and VisualCoreSimulation (`StableHash`); in the
experience tests VisualCoreRendering (`ProcessMemory`) and the experience host. No new package, target, VisualCore API
or app change.
**Seeds**: no new randomness; the golden set and the alterations are fixed lists.
**Testing**: host `swift test --package-path Packages/ExperiencesRound02 --filter AuroraLoomRegression`; simulator
`--only-testing` of the golden and memory test classes; the regression as in 307.
**Performance**: the solver regression re-solves 100 levels (each at most 3,840 evaluations) and regenerates them,
split into five band tests; golden descriptions are pure CPU work for 16 frames at 768 × 512. Counted, never timed.
**Constraints**: additive; the only experience change is a test-visible live GPU object count on the ribbon scene.
