## Derived values (geometry, all from the snapshot)

- Position of kernel point p: k · p / 2²⁰. Orbit vertex i: table point i (R2). Body at the shown tick t: `[t − 1]`.
- Star radius: 0.05 + 0.012 · (luminosity index); core radius half that. World radius: 0.07; world pips: j + 1.
- Tilt dial: T_max + 1 pips from (−1.15, 1.08, 0) in steps of 0.05 (none when T_max = 0); pip τ filled.
- Gauge row j: y = −1.2 − 0.1 · j; plate x −0.95 … 1.22; cell t at x −0.9 + (t − 0.5) · 1.8/48, width 1.8/48 · 0.8,
  height 0.01 + 0.06 · min(1, F/λ_hi); guide lines at the heights of c_lo and c_hi; window bracket from windowStart over
  longestWindow cells (two pieces when it wraps past tick 48), required tick at W cells, solid when longestWindow ≥ W;
  tick marker above column t; bloom meter x 0.97 … 1.2 over 0 … max(1, 2 · B_hi), bracket B_lo … B_hi, marker at
  min(I, 2 · B_hi).
- Actions bars: y = −1.2 − 0.1 · worlds − 0.03; `budget` bars, each 1.8 / budget wide with a fifth as gap, 0.035 tall,
  the first `actionsLeft` lit.
- Failure column: ((tick − 1) mod 48) + 1. Trail ticks: ((t − 1 − a) mod 48) + 1 for age a = 1 … trail length.
