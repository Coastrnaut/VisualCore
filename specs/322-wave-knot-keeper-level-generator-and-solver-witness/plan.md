# Implementation Plan: R02-G03-02 — Wave Knot Keeper: level generator and solver witness

**Branch**: `322-wave-knot-keeper-level-generator-and-solver-witness` (spec directory only; work on `main`) | **Date**:
2026-11-21 | **Spec**: [spec.md](spec.md)

## Summary

Extend `WaveKnotKeeperCore` (R02-G03-01, feature 321) with the content pipeline of Wave Knot Keeper: the 100-entry
manifest (`WaveKnotKeeperManifest`), the solver (`WaveKnotKeeperSolver`: a breadth-first search over legal ropes to depth
3 with the crossing counterexample found on the way), difficulty metrics (`WaveKnotKeeperDifficulty`), the seeded
generator (`WaveKnotKeeperGenerator`: solved rope, gates, scramble walk, tension bound, candidates until one is proven
within its band) and versioned witness files (`WaveKnotKeeperWitness`, schema 1) under
`docs/games/wave-knot-keeper/levels/`. The catalog digest is R02-F24's
`PuzzleCatalog<WaveKnotKeeperRules>.digest(id:identities:)`, pinned. Research: [research.md](research.md). Data:
[data-model.md](data-model.md). API: [contracts/api.md](contracts/api.md). Quickstart: [quickstart.md](quickstart.md).

## Technical Context

**Language/Version**: Swift 6. **Primary dependencies**: WaveKnotKeeperCore's own types (`WaveKnotKeeperLevel`,
`WaveKnotKeeperPlay`, `WaveKnotKeeperRules`, `WaveKnotKeeperGeometry`); VisualCoreSimulation (`SeededRandom`,
`SeedDerivation`, `PuzzleCatalog.digest`, `ProgressionRule`); VisualCoreMath (`StableHash`). No GPU, GLSL or UIKit code;
no new package or target.
**Seeds**: level n uses its manifest seed; candidate k draws from `SeededRandom(seed: SeedDerivation.derive(seed, index:
k))`, k = 0 … 63. Brute-force cross-checks use `SeededRandom(seed: 2_322)`.
**Testing**: `swift test --package-path Packages/ExperiencesRound02` (CI step exists); regression: VisualCore host tests,
VisualCoreRendering on sim-27.2 and sim-26.5, ExperiencesCreative on sim-27.2, the app unit tests, the reference
regression in two chunks, script tests (alone).
**Performance**: the search expands at most 3,661 ropes per level (≤ 10 points × 6 directions, depth 3), each child
checked by the kernel's legality (sweep against ≤ 10 segments) and win test (≤ 45 segment pairs). Target: a level's
generation under 0.1 s on a debug host build on average; the catalog tests are split by band (20 levels each) so each
stays under 10 s; CI timings are measured, never asserted.
**Constraints**: additive to R02-G03-01's public API; allowance = the manifest move budget (8 … 19); every value an exact
integer; no network, no art; witness files written only with `WAVE_KNOT_KEEPER_WRITE_WITNESSES=1`.

## Parallel work

Lead first adds the error cases, the manifest, the solution and difficulty contract (contracts/api.md) and the difficulty
type; agents A (solver and its tests) and B (witness and its tests) then work in parallel against the contract; the lead
writes the generator, the catalog tests and the witness files once A's solver is in, retests every agent result and
records checks only after every agent has reported.
