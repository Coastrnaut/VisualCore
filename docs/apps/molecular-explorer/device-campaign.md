# Molecular Explorer — device campaign plan (A15-P06, feature 115)

These measurements need real devices and run only after `ImplementationLock-100` (CLAUDE.md rule 5), in the order
D1 → D2 → D3. Until then every row is pending; no pacing, thermal, memory or accessibility number is claimed anywhere.
Simulator results never stand in for these rows. Every row is a {device} task (research D5; FR-A15-620). Molecular
Explorer has one drawing level, `level-0` (one unit sphere of 32 segments and 16 rings, one unit stick of 16 sides; at
most 82 items for the library, within the draw budget of 1,500), so there is no level drop to measure; caffeine is the
largest library molecule (24 atoms, 25 bonds, 58 sticks in ball and stick).
