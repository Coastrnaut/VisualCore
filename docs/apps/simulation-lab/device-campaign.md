# Simulation Lab — device campaign plan (A16-P06, feature 122)

These measurements need real devices and run only after `ImplementationLock-100` (CLAUDE.md rule 5), in the order
D1 → D2 → D3. Until then every row is pending; no pacing, thermal, memory or accessibility number is claimed anywhere.
Simulator results never stand in for these rows; the steps per second of
[validation-report.md](validation-report.md) are simulator figures, not device claims. Every row is a {device} task
(research D5; FR-A16-620). Simulation Lab has one drawing level, `level-0` (`Catalog/registrations.json`), so there is
no level drop to measure. The grid is 64 × 64 cells for every family; at ×4 a frame runs at most 16 GPU steps (the
engine's cap is 128, `GPURebuildTests`), and the presenter's targets hold 180,224 bytes (validation report).
