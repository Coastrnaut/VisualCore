# Infinite Geometry (`a05.infinite-geometry`)

An animated geometry laboratory for tilings, kaleidoscopes, procedural objects and camera-driven compositions
(archived manual `apps/05-infinite-geometry.md` §1). Audiences: visual-art hobbyists, designers exploring symmetry and
pattern families, and learners who benefit from geometric demonstrations (§2).

Infinite Geometry is an experience of the one VisualCore app (ADR-0009), built in
`Packages/ExperiencesCreative/InfiniteGeometry` from Phase 01 on; it never has a standalone target. Its rules are the
A05 subsection of the constitution (2.1.0).
