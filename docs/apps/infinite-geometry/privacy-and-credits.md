# Infinite Geometry — privacy and credits

Infinite Geometry is the experience `a05.infinite-geometry` of the one VisualCore app (ADR-0009). It has no app
target, Info.plist or privacy manifest of its own: the app's declarations cover it. Feature 045 (A05-P06),
FR-A05-601 and FR-A05-604. Sources: `Packages/ExperiencesCreative/InfiniteGeometry` (below: IG).

## What is stored on the device

| What | Where | Written by | Content |
|---|---|---|---|
| Saved compositions | `composition-<uuid>.json` in the experience's own storage folder, `Application Support/Experiences/a05.infinite-geometry/` | `IG/Experience/GeometryLibrary.swift` through `ExperienceStorage.write` (atomic replace, quota of `StorageQuota`: at most 64 files and 16 MiB) | The composition the person saved under a name (format 1): the `GeometryDocument` (preset, palette, motif seed and both views), the state digest at save time, the id and the saved time |
| Saved session state | `state.json` in the same folder | the app (`SavedStateStore`, `Apps/VisualCore/App/AppModel.swift`), not the experience | The session snapshot of `GeometryCore` (`IG/Experience/Adapter/GeometryCore.swift`): the seed, the preset and the two views, so that the experience can resume |

Nothing else is persisted by the experience. Its sources write no named defaults values (`ExperienceStorage.setValue`
is not called), no other files and no `UserDefaults` values. Damaged files and files of a newer format or document
version are counted and kept, never deleted or rewritten (`GeometryLibrary`). Removing the app removes the folder.

## Exported pictures

"Export picture" renders the composition off screen through the host's still renderer and encodes it as a PNG
(`IG/Experience/GeometryExport.swift`). The PNG is held in memory only: no file of the app's own is written and no
metadata is added. It leaves the experience only when the person passes it on through the system share sheet
("Share picture", a `ShareLink` in `IG/Experience/GeometryControls.swift`); where it goes is the person's choice in
that sheet. The experience never saves to the photo library itself.

## What is not done

- **No collection.** Nothing the person makes is sent anywhere by the experience; there is no upload, sync or account.
  The only way out is the share sheet above, started by the person.
- **No permission.** Infinite Geometry asks for none and adds no usage string. The app's only usage string is
  `NSPhotoLibraryAddUsageDescription`, which belongs to A01 (Generative Art Studio).
- **No network.** The sources contain no `URLSession`, `Network`, tracking, advertising, motion, location or media
  framework use (check `ig-no-network`, T-A05-603). The app tracks nothing (`NSPrivacyTracking` false, no tracking
  domains).
- **No sensors.** The drawn detail of the 3D composition follows the quality level the host sets
  (`GeometryCore.setQualityTier`); the host's `QualityGovernor` decides it from the thermal state and Low Power Mode
  (public `ProcessInfo` state). The experience reads neither itself.

## Required-reason APIs and the app's privacy manifest

The app manifest `Apps/VisualCore/Resources/PrivacyInfo.xcprivacy` declares no tracking, no collected data types and
three accessed-API categories. The experience's uses fall under them:

| Category and reason | Use by Infinite Geometry |
|---|---|
| `NSPrivacyAccessedAPICategoryFileTimestamp`, `C617.1` | `ExperienceStorage` reads file attributes (`attributesOfItem`: type and size) of the experience's own files when the library lists, reads or writes compositions |
| `NSPrivacyAccessedAPICategoryUserDefaults`, `CA92.1` | `ExperienceStorage` holds the app's `UserDefaults` for named values under the prefix `exp.a05.infinite-geometry.`; Infinite Geometry stores none |
| `NSPrivacyAccessedAPICategorySystemBootTime`, `35F9.1` | Frame times and quality decisions come from the app's render host (`ExperienceSession`); the experience's sources read no boot time. Elapsed time inside the app only |

The built product is checked against this manifest by `release_check.py --only app-release-build
app-privacy-manifest app-no-tracking` ([build-and-archive](../../release/build-and-archive.md)).

  are this repository's own code. It depends only on the local packages `Packages/VisualCore` and
  `Packages/VisualCoreRendering` (`Packages/ExperiencesCreative/Package.swift`); it adds no third-party package. The
  app's third-party components (ANGLE and the libraries inside it, listed in `docs/legal/third-party.json`) are bundled
  under the app's `Licenses` folder, shown in the app's Acknowledgements and checked by `app-licenses`.
- **Assets.** None. Every tiling, kaleidoscope, motif, mesh and palette is generated by code; no third-party art, font
  or data is used. The only non-Swift file under IG is `scenario-manifest.json`, which is outside every target's path
  (test fixtures of A05-P06 are resources of the test target only). No image, sound or model is bundled.
- **ProjectM.** Not used; ProjectM types stay out of the app.
