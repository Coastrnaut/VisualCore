# Particle Universe — VisualCore contract (A04-P00)

Read this before editing graphics integration (manual §6, §8). It holds the evidence-backed integration matrix, the
inventory, the gap register and the stop/go decision of Phase 00 (spec `specs/032-pu-p00-boundary-audit`). The data
lives in [`visualcore-contract.json`](visualcore-contract.json). Verify it with
`python3 scripts/check_app_contract.py --app particle-universe`, and regenerate the block below with `--render`.

The particle simulation runs on the CPU in VisualCore's deterministic `ParticleSystem` (the OpenGL ES path has no
compute shaders); only drawing uses the GPU. Generic particle machinery goes to VisualCore:
- fixed-step stepping and emitter shapes (VisualCoreSimulation);
- force fields (VisualCoreSimulation);
- particle-count quality tiers (VisualCoreDiagnostics);
- additive blending and trail decay (VisualCoreRendering).

Curated presets, the scene schema, copy and UI stay in the app.

### Decision

**GO**

- Every capability maps to existing VisualCore API (5 available: buffer management, instanced rendering, interaction parameters, size/lifetime/gradient, pause/reseed/save) or an additive gap (5 adaptation rows).
- All gaps are additive and reusable: G-SIMSTEP and G-EMITTERS and G-FIELDS (VisualCoreSimulation), G-PQUALITY (VisualCoreDiagnostics), G-BLENDTRAIL (VisualCoreRendering); scene presets stay app content on NamedLibrary. None needs a second renderer, compute shaders, a fork, private API or networking.
- The simulation stays on the CPU (deterministic, bounded) and only drawing uses the GPU, because the OpenGL ES path offers no compute shaders (research R1); counts are capped and tiered (risk 3), additive blending gets a reduced-flash cap (risk 2), and instanced drawing is already proven by A01 (risk 1).
- Reference regression baseline recorded green 7/7 (T-A04-003) and the empty shell builds and passes its smoke test on both simulator runtimes (T-A04-005).
- Phase 01 starts with G-SIMSTEP and G-EMITTERS in VisualCoreSimulation and the app's seeded scene model.
