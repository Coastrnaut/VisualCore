# Particle Universe — privacy and credits

Particle Universe is the experience `a04.particle-universe` of the one VisualCore app (ADR-0009). It has no app
target, Info.plist or privacy manifest of its own: the app's declarations cover it. Feature 038 (A04-P06),
FR-A04-603 and FR-A04-604. Sources: `Packages/ExperiencesCreative/ParticleUniverse` (below: PU).

## What is stored on the device

| What | Where | Written by | Content |
|---|---|---|---|
| Saved scenes | `scene-<uuid>.json` in the experience's own storage folder, `Application Support/Experiences/a04.particle-universe/` | `PU/Experience/ParticleLibrary.swift` through `ExperienceStorage.write` (atomic replace, quota of `StorageQuota`) | The scene the person saved under a name: emitters, the placed force, the look, the saved time |
| Saved session state | `state.json` in the same folder | the app (`SavedStateStore`, `Apps/VisualCore/App/AppModel.swift`), not the experience | The session snapshot of `ParticleCore` (`PU/Experience/Adapter/ParticleCore.swift`): the seed and the logged actions, so that the experience can resume |

Nothing else is persisted by the experience. Its sources write no named defaults values (`ExperienceStorage.setValue`
is not called) and no other files. The only `UserDefaults` reads in PU are the `uitest*` launch arguments of
`PU/Experience/DeviceConditionsSource.swift`, compiled in `DEBUG` builds only. Damaged and newer scene files are
counted and kept, never deleted or rewritten (`ParticleLibrary.reload()`). Removing the app removes the folder.

## What is not done

- **No collection and no sharing.** Nothing the person makes leaves the device; there is no upload, sync, export or
  sharing path in the experience.
- **No permission.** Particle Universe asks for none and adds no usage string. The app's only usage string is
  `NSPhotoLibraryAddUsageDescription`, which belongs to A01 (Generative Art Studio).
- **No network.** The sources contain no `URLSession`, `Network`, tracking, advertising, motion, location or media
  framework use (check `pu-no-network`, T-A04-604). The app tracks nothing (`NSPrivacyTracking` false, no tracking
  domains).
- **No sensors.** Heat and Low Power Mode are read through VisualCore's `DeviceConditions.current()` (public
  `ProcessInfo` state), only to lower the drawn detail.

## Required-reason APIs and the app's privacy manifest

The app manifest `Apps/VisualCore/Resources/PrivacyInfo.xcprivacy` declares no tracking, no collected data types and
three accessed-API categories. The experience's uses fall under them:

| Category and reason | Use by Particle Universe |
|---|---|
| `NSPrivacyAccessedAPICategoryFileTimestamp`, `C617.1` | `ExperienceStorage` reads file attributes (`attributesOfItem`: type and size) of the experience's own files when the library lists, reads or writes scenes |
| `NSPrivacyAccessedAPICategoryUserDefaults`, `CA92.1` | `ExperienceStorage` holds the app's `UserDefaults` for named values under the prefix `exp.a04.particle-universe.`; Particle Universe stores none. The `DEBUG`-only launch-argument reads above use the same API |
| `NSPrivacyAccessedAPICategorySystemBootTime`, `35F9.1` | Frame times come from the app's render host; `SceneModel` (compiled with the experience for the standalone target until X-A04) reads `ProcessInfo.systemUptime` for its quality controller. Elapsed time inside the app only |

The built product is checked against this manifest by `release_check.py --only app-release-build
app-privacy-manifest app-no-tracking` ([build-and-archive](../../release/build-and-archive.md)).

## Credits

- **Code.** The experience's sources are this repository's own code. It depends only on the local packages
  `Packages/VisualCore` and `Packages/VisualCoreRendering` (`Packages/ExperiencesCreative/Package.swift`); it adds no
  third-party package. The app's third-party components (ANGLE and the libraries inside it, listed in
  `docs/legal/third-party.json`) are bundled under the app's `Licenses` folder, shown in the app's Acknowledgements and
  checked by `app-licenses`.
- **Assets.** None. Every particle, colour gradient and trail is generated by code; the only non-Swift files under PU
  are test fixtures (resources of the test targets `CoreTests/Fixtures`, `ExperienceTests/Fixtures`) and
  `scenario-manifest.json`, which is outside every target's path. No image, sound or model is bundled.
- **ProjectM.** Not used; ProjectM types stay out of the app.
