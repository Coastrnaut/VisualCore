# Fluid Art Playground — VisualCore contract (A02-P00)

Read this before editing graphics integration (manual §6, §8). It is the evidence-backed integration matrix,
inventory, gap register and stop/go decision of Phase 00 (spec `specs/018-fap-p00-boundary-audit`). The data lives in
[`visualcore-contract.json`](visualcore-contract.json). Verify it with
`python3 scripts/check_app_contract.py --app fluid-art-playground`, and regenerate the block below with `--render`.

The solver equations (advection, divergence, Jacobi pressure, projection, splats) stay in the app with a CPU
reference (constitution A02). The machinery they run on is reusable and goes to VisualCore: ping-pong targets,
field passes, the half-float support query, pointer velocity and quality policy.

### Decision

**GO**

- Every capability maps to existing VisualCore API (4 available: feedback, blending/post, pause/reset/seeded, still capture) or an additive gap (6 rows).
- All 6 gaps are additive: five reusable VisualCore helpers (PingPongTarget, half-float support query, FieldPass, PointerVelocityTracker, QualityPolicy) owned per Principle II, and the solver equations kept app-local with a CPU reference by the A02 rule. None needs a second renderer, a fork, private API or networking.
- Half-float targets are not assumed: support is queried and an RGBA8 fallback is planned (G-FLOATRT), so no unverified GPU feature is a dependency.
- Reference regression baseline recorded green 7/7 (T-A02-003) and the empty shell builds and passes its smoke test on both simulator runtimes (T-A02-005).
- Phase 01 starts with G-PINGPONG, G-FLOATRT and G-FIELDPASS in VisualCoreRendering and the app's GPU-free solver reference.
- A02-P05: MVP-05 (pause, step, reset, deterministic seeded test mode) and MVP-06 (simulation detail) are implemented; the manual's fixtures 1-5 pass as one suite; a 600-frame stress run found and fixed unbounded splats in half-float storage; device stress automation is ready and rehearsed on simulators only (device runs pending the implementation lock).
- A02-P06: release-ready on simulators: privacy manifest equals the Release scan (2 categories), one usage string, nothing persisted, icon from the app's own render, bundled licenses, release check 13/13; device rows pending campaign II and owner-only store steps recorded.
