## Stop/go narrative

**Go.** VisualCore already provides the render host, resources, render targets, effects, procedural geometry, touch
input and seeded simulation the app needs. The missing pieces are reusable, so under the owner's reuse rule they
become VisualCore work in the phase that first needs them:

1. **Phase 01:** a new pure module `VisualCoreParameters`.
2. **Phase 02:** in `VisualCoreRendering`, a shader bundle loader and a GLSL include library; in
   `VisualCoreSimulation`, a scene clock; and in `VisualCoreUI`, the SwiftUI surface and accessibility settings.
3. **Phase 03:** the `VisualCorePersistence` envelope, atomic writes and migrations.
4. **Phase 04:** a still exporter in `VisualCoreRendering`.

Each upstream change ships with package tests, docs, an API-baseline update and the ProjectM regression
(constitution II-a). Capabilities that exist only in the ProjectM reference are not available to the app and are never
linked.
