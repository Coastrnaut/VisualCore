# Fractal Explorer — privacy and credits

Release candidate 1.0.0 (1). This page is based on the app's actual behavior, its tests and a scan of the Release
build (`scripts/check_privacy_manifest.py`). It is not sample text.

## Data

| What | Where | Leaves the device? |
|---|---|---|
| Bookmarks the person saves (name, place, settings, precision mode) | `Library/Application Support/Bookmarks`, one JSON file each (VisualCore `NamedLibrary`, schema 1) | No |
| The latest captured picture | the app's temporary folder `tmp/Captures`; removed when the explorer closes and at every launch (`CaptureTests`, `CrashRecoveryTests`) | Only when the person shares or saves it through the system share sheet |

- No settings are stored: 0 app keys in the app's defaults (`PrivacyTests.testSessionStoresOnlyTheSavedBookmark`).
- The app has no account, analytics, advertising, tracking or network code (`check_app_isolation.py`).
- Touches move the view only; they are never recorded.
- `Library/LanguageModeling/<language>-dynamic.lm` may appear after typing a bookmark name or coordinates. iOS's
  keyboard creates it; the app never reads or writes it (provenance checked in the simulator container).
- Privacy manifest: `NSPrivacyTracking` false, no tracking domains, no collected data types.
- App Store privacy label: **Data Not Collected**.
- Debug and automation builds may write automation reports (`visualcore-automation-*.json`) to Documents for the
  device campaign; the Release build has 0 automation symbols (`check_release_symbols.py`).
- Migration: bookmark schema 1 is fixed by the committed fixture `Apps/FractalExplorer/Tests/Fixtures/bookmark-v1.json`
  (`MigrationTests`); a later schema adds a migration step and a new fixture.

## Permissions

| Permission | Usage text | When iOS asks | UI path |
|---|---|---|---|
| Photos, add only (`NSPhotoLibraryAddUsageDescription`) | "Fractal Explorer saves your captured picture to Photos only when you choose Save Image." | Only if the person picks **Save Image** in the share sheet | Explorer → Capture → Share picture → Save Image |

No other permission is declared or requested (`PrivacyTests.testOnlyPhotosAddUsageStringIsDeclared`).

## Required-reason APIs (privacy manifest)

| Category | Reason | Where the use is |
|---|---|---|
| File timestamp | C617.1: files inside the app container | `stat` in ANGLE's `libEGL` (same pinned build as A01/A02); the bookmark store reads its own files' sizes |
| System boot time | 35F9.1: elapsed time inside the app | `CACurrentMediaTime` and `systemUptime` for frame timing, the tour clock and automation (VisualCore and app), and `mach_absolute_time` in ANGLE's `libGLESv2` |

Scan result (`A03-P06/t601-privacy-scan`): 2 categories detected = 2 declared.
