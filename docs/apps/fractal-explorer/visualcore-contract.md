# Fractal Explorer — VisualCore contract (A03-P00)

Read this before editing graphics integration (manual §6, §8). It holds the evidence-backed integration matrix, the
inventory, the gap register and the stop/go decision of Phase 00 (spec `specs/025-fe-p00-boundary-audit`). The data
lives in [`visualcore-contract.json`](visualcore-contract.json). Verify it with
`python3 scripts/check_app_contract.py --app fractal-explorer`, and regenerate the block below with `--render`.

The escape-time formulas (Mandelbrot, Julia, smooth escape value) stay in the app with a CPU reference (constitution
A03). The machinery they run on is reusable and goes to VisualCore:
- the double-precision complex-plane viewport and tour interpolation;
- the shader-precision query and advisor;
- the render-cost estimate.

Precision is an engineering limit of the OpenGL ES shader path. It is clamped and shown, never solved with a second
renderer.

### Decision

**GO**

- Every capability maps to existing VisualCore API (6 available: fragment shaders, animation, palettes, pinch/pan, bookmarks, capture) or an additive gap (4 adaptation rows).
- All gaps are additive: G-VIEWPORT and G-TOUR (VisualCoreMath), G-PRECISION (VisualCoreRendering query + VisualCoreMath advisor) and G-COST (VisualCoreDiagnostics) are reusable helpers owned per Principle II; the escape-time formulas stay app-local with a CPU reference by the A03 rule (G-FRACTAL). None needs a second renderer, a fork, private API or networking.
- Double precision on the GPU is not assumed: 32-bit shader floats are the baseline, zoom is clamped at the measured limit and the limit is shown (A03 truthful precision); perturbation and emulated double stay later ideas.
- Reference regression baseline recorded green 7/7 (T-A03-003) and the empty shell builds and passes its smoke test on both simulator runtimes (T-A03-005).
- Phase 01 starts with G-VIEWPORT in VisualCoreMath and the app's GPU-free escape-time reference (G-FRACTAL).
- A03-P01: Mandelbrot and Julia modes with accessible explanations and spoken descriptions run on a deterministic CPU reference preview (no GPU yet); PlaneViewport closes G-VIEWPORT in VisualCoreMath and FractalMath closes G-FRACTAL with the known-point fixtures; ProjectM regression 7/7.
- A03-P02: the escape-time shader runs in VisualCore's FullScreenShaderScene behind RenderHost (EGL owned only by the host) and matches the FractalMath CPU reference on 64x64 grids (Mandelbrot 100%, Julia 99.9% boundary-only); anchored pinch/pan keeps the plane point under the fingers within 1e-9; five palettes with Reduce-Motion-aware animation; G-PRECISION closed (RenderCapabilities fragment precision + PrecisionAdvisor) with a visible, announced zoom clamp; ProjectM regression 7/7.
- A03-P03: bookmarks keep mode, framing, seed, cap, radius, palette and precision mode in a VisualCore NamedLibrary and reopen exactly on any canvas shape (center bit-exact, span within 1e-12); a bookmark deeper than this device's precision opens clamped with a note; Go to coordinates; resizes keep the framing with square pixels (GPU 64x32 and 32x64 match the CPU reference 100%); G-FRAMING and G-LIBRARY closed; ProjectM regression 7/7.
- A03-P04: an adjustable iteration cap with a relative render-cost line (G-COST); 4096 px captures that agree 64/64 with the CPU reference, limited by the device and by precision, shared through the system sheet (G-CAPTURE); three curated tours on log-scale flights with announced captions and Reduce Motion jumps (G-TOUR); the precision advisor checked against real float32/float16 spacing; ProjectM regression 7/7.
- A03-P05: device precision and performance validation is automation-ready — VisualCore app modes (G-AUTOMODE) carry the app's `precision` ladder and `tour` modes; all five modes pass a simulator rehearsal on 27.2 and 26.5 (not device evidence); bookmarks reproduce identical pictures; the shipping Release has no automation; the D1/D2/D3 rows are pending the implementation lock.
- A03-P06: release-ready on the simulator side — privacy manifest from the Release scan (2 = 2), Data Not Collected, no networking, icon from the app's own render, Acknowledgements from bundled licenses, bookmark schema 1 frozen by a committed fixture, crash recovery, truthful copy traced to tests, release check 13/13; device rows pending campaign II and owner steps BLOCKED_OWNER_ACTION.
