# Oscilloscope Studio — VisualCore contract (A08-P00)

Read this before editing audio or graphics integration of the experience `a08.oscilloscope-studio`. It holds the
evidence-backed integration matrix, the inventory, the gap register and the stop/go decision of Phase 00 (spec
`specs/060-os-p00-boundary-audit`). The data lives in [`visualcore-contract.json`](visualcore-contract.json). Verify it
with `python3 scripts/check_app_contract.py --app oscilloscope-studio`, and regenerate the block below with `--render`.

Oscilloscope Studio is an experience of the one VisualCore app (ADR-0009), not a standalone app. It reuses the audio
products built for A06 (VisualCoreAudio, VisualCoreAudioDSP) unchanged. Generic scope machinery goes to VisualCore:
- square and sweep demo signals, trigger detection with a timebase window and min/max display decimation
  (VisualCoreAudioDSP);
- two-channel (stereo) capture for the XY view (VisualCoreAudio);
- bounded multi-point trace strips (VisualCoreScenes, drawn by VisualCoreRendering).

Only the spectrum axis wording, the XY plot, freeze and cursors, the spoken measurement description and the accuracy
statements stay in the experience. Levels are relative dBFS; nothing is calibrated, certified or laboratory-grade.
